## 📖 Overview

**OM Media & Productions** is a high-end cinematic wedding media and film studio founded by **Vinod Kumar**, operating out of **Varanasi, Uttar Pradesh**. 

Inspired by the cultural heritage of Kashi—where golden morning light washes over sandstone ghats, Vedic chants sanctify eternal vows, and Banarasi silks gleam with generational artistry—the studio blends timeless heritage with modern film-industry standards. 

Operating multi-camera cinema rigs, prime optics, a 32ft Jimmy Jib crane, dual 4K aerial drones, and 32-bit float audio capture, OM Media & Productions crafts heirloom wedding films and editorial photography across **Varanasi, Lucknow, Prayagraj, Ayodhya, Kanpur, Agra, Mathura-Vrindavan, Noida, Gorakhpur, and premier destination venues throughout India**.

## 🚀 Getting Started

### Prerequisites
Make sure you have installed:
- **Node.js**: v18.18.0 or higher (v20+ recommended)
- **npm** (or `pnpm` / `yarn`)
- **Git**

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Master-Shubh/Om-Media-Production.git
   cd Om-Media-Production
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the local development server:**
   ```bash
   npm run dev
   ```

4. **View in browser:**
   Open [http://localhost:3000](http://localhost:3000) in your web browser.

---

## 🛠️ Build & Production Deployment

To generate an optimized, standalone production build:

```bash
# Compile and optimize for production
npm run build

# Start the production server
npm run start
```

### Deploy to Vercel (Recommended)
The easiest way to deploy this Next.js project is with [Vercel](https://vercel.com):
1. Push your code to GitHub.
2. Import your repository on the [Vercel Dashboard](https://vercel.com/new).
3. Next.js will be automatically detected with zero configuration required.
4. Click **Deploy**.

Open `lib/data.ts` and locate `siteConfig`:
```typescript

  },
  location: {
    city: "Varanasi",
    state: "Uttar Pradesh",
```

### Adding New Portfolio Stories:
Add a new object to `portfolioStories` in `lib/data.ts` with couple names, venue, date, story excerpt, film embed URL, and gallery photos. The dynamic route `/portfolio/[slug]` will automatically generate the dedicated case study page!
